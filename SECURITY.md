# Security Policy

## Reporting a Vulnerability

If you discover a security issue, please report it via [GitHub Security Advisories](https://github.com/20kiki/update-github-hosts/security/advisories/new).

**Do not open a public issue.**

## Scope

This tool modifies the system hosts file with administrator/root privileges. If you find a vulnerability that could allow unauthorized hosts modification, please report it as described above.
